# Student Profile Repository — Team 4

## 1. Project Overview

This repository is for the Web Development Lab activity at BossCoder School of Technology.

Our team is building a shared student profile website using HTML, Git, and GitHub. Each developer creates one assigned HTML page on an individual feature branch and submits a Pull Request (PR) to the `main` branch. The Team Lead reviews and merges approved PRs.

## 6. Developer Workflow

Each developer must perform their own work and run their own Git commands:

1. Clone this repository.
2. Create the assigned feature branch.
3. Create and edit the assigned HTML file.
4. Stage and commit the changes.
5. Push the feature branch to GitHub.
6. Open a Pull Request with `main` as the base branch.

Example commands (replace the branch and file names with your own assignment):

```bash
git clone https://github.com/instinct-coder1/Web-Dev-Lab_Exercise.git
cd Web-Dev-Lab_Exercise
git switch -c feature/your-feature
git add your-file.html
git commit -m "Add assigned student page"
git push -u origin feature/your-feature
```

## 7. Team Lead and Reviewer Responsibilities

The Team Lead is responsible for:

- Maintaining this README and coordinating the team.
- Ensuring all members have the required repository access.
- Checking that each PR targets `main`.
- Reviewing the changed file and checking that it matches the member's assignment.
- Requesting corrections when a PR needs changes.
- Approving and merging only suitable PRs.
- Verifying that all three HTML pages are present in `main` after merging.

The Team Lead does not create or submit feature work on behalf of the developers. Each developer must demonstrate their own branch, commits, and Pull Request.
